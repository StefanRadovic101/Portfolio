# Microsoft Fabric – End-to-End Sales Analytics

End-to-end sales analytics project built in Microsoft Fabric, covering data ingestion, Lakehouse architecture, SQL transformations, semantic modeling, DAX, and Power BI reporting.

## Project Workflow

1. Built a Microsoft Fabric data pipeline to ingest sales data into a Lakehouse.
2. Created and transformed FactSales, DimCustomer, DimProduct, and DimDate tables using SQL.
3. Designed a star-schema semantic model connecting the fact and dimension tables.
4. Created DAX measures for Total Net Sales, Total Orders, Average Order Value, and YoY Sales Growth.
5. Built an interactive Power BI Executive Sales Overview.
6. Used Power BI Copilot to assist with report creation and visualization.

## Dashboard

The dashboard includes:
- Total Net Sales
- Total Orders
- YoY Sales Growth
- Net Sales Trend
- Net Sales by Region
- Net Sales by Product Category
- Year and Region slicers
