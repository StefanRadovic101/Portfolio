# Microsoft Fabric – End-to-End Sales Analytics

End-to-end sales analytics solution built in Microsoft Fabric, covering data ingestion, transformation, lakehouse architecture, SQL analytics, semantic modeling, DAX, and Power BI reporting.

## Project Workflow

1. Built a data ingestion pipeline in Microsoft Fabric to load sales data into a Lakehouse.
2. Created and transformed analytical tables using SQL, including FactSales, DimCustomer, DimProduct, and DimDate.
3. Designed a star-schema semantic model with one-to-many relationships between dimension and fact tables.
4. Created DAX measures for key business KPIs, including Total Net Sales, Total Orders, Average Order Value, and YoY Sales Growth.
5. Built an interactive Power BI Executive Sales Overview connected to the Fabric semantic model.
6. Used Power BI Copilot to assist with report generation and visualization.

## Dashboard

The executive dashboard provides:

- Total Net Sales
- Total Orders
- YoY Sales Growth
- Net Sales Trend
- Net Sales by Region
- Net Sales by Product Category
- Interactive Year and Region filters
